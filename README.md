# dejaVu Repository

Official Kodi repository for [dejaVu.plus](https://dejavu.plus) addons.

[Français](#français) · [English](#english)

## Français

Dépôt Kodi officiel des extensions dejaVu. Il permet d’installer et de mettre à jour les addons qui synchronisent films et séries avec [dejaVu.plus](https://dejavu.plus).

Ce n’est pas un scraper : il ne fournit aucun flux.

**Prérequis :** Kodi 19+ (Python 3).

### Addons

- **[script.dejavu](https://github.com/doctornono/script.dejavu)** — addon principal : scrobble, watchlist, favoris, collection, DejaVu Connect, import de la bibliothèque Kodi.
- **[skin.dejavu](https://github.com/doctornono/skin.dejavu)** — habillage pour Kodi avec intégration avancée de script.dejavu
- **repository.dejavu** — ce dépôt.

### Installation

1. Dans Kodi, aller dans `Paramètres > Gestionnaire de fichiers`.
2. Choisir `Ajouter une source`.
3. Ajouter l’URL : `https://doctornono.github.io/`.
4. Donner un nom à la source, par exemple : `dejaVu`.
5. Aller dans `Extensions > Installer depuis un fichier ZIP`.
6. Ouvrir la source `dejaVu`.
7. Installer `repository.dejavu-1.0.0.zip`.
8. Aller dans `Extensions > Installer depuis un dépôt > Dépôt dejaVu`.
9. Installer `dejaVu`.

Une fois le dépôt installé, Kodi propose les mises à jour automatiquement.

Ensuite, connectez-vous à dejaVu.plus depuis les réglages de l’addon (QR code). Aucun mot de passe n’est saisi dans Kodi.

Site : [dejavu.plus](https://dejavu.plus)

## English

Official Kodi repository for dejaVu addons. It installs and updates the addons that sync movies and TV shows with [dejaVu.plus](https://dejavu.plus).

This is not a scraper: it does not provide streams.

**Requirements:** Kodi 19+ (Python 3).

### Addons

- **[script.dejavu](https://github.com/doctornono/script.dejavu)** — main addon: scrobble, watchlist, favorites, collection, DejaVu Connect, Kodi library import.
- **[skin.dejavu](https://github.com/doctornono/skin.dejavu)** — skin for kodi with full integration of script.dejavu
- **repository.dejavu** — this repository.

### Install

1. In Kodi, go to `Settings > File manager`.
2. Choose `Add source`.
3. Add the URL: `https://doctornono.github.io/`.
4. Name the source, for example: `dejaVu`.
5. Go to `Add-ons > Install from zip file`.
6. Open the `dejaVu` source.
7. Install `repository.dejavu-1.0.0.zip`.
8. Go to `Add-ons > Install from repository > dejaVu Repository`.
9. Install `dejaVu`.

Once the repository is installed, Kodi offers updates automatically.

Then sign in to dejaVu.plus from the add-on settings (QR code). No password is typed in Kodi.

Website: [dejavu.plus](https://dejavu.plus)
